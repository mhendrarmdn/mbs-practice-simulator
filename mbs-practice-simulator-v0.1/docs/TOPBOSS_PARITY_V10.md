## Financial Statement parity target

The recovered walkthrough explicitly treats the Financial Statement screen as the final reconciliation page and says it contains:

- Balance Sheet
- Cash Flow
- Income Statement

The v1.0 UI now mirrors that three-part structure rather than presenting only a few KPI cards.

## Financial Ratio parity target

- Current Ratio

- Inventory Turnover
- Fixed Asset Turnover
- Total Asset Turnover
- Debt Ratio
- Times Interest Earned
- Net Profit Margin
- Basic Profit Margin
- ROA
- ROE
- ROCE

These now have a dedicated Analysis → Financial Ratio page.
