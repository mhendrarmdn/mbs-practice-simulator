# Changelog

## v0.2.0

- Added Light / Dark / System themes with browser persistence.
- Added Training, Competition, and Sandbox modes.
- Added Competition countdown timer and decision locking.
- Added Sensitivity Lab for Price, Marketing, R&D, and Production.
- Made AI strategies adaptive to profit, inventory, share, and overdraft conditions.
- Added Scenario Center and persistent surprise-event history.
- Added financial health alerts on the dashboard.
- Improved Decision History with round-over-round profit delta.
- Added export/import save game JSON.
- Added Model Transparency page separating observed calibration anchors from training-model proxies.
- Preserved optional Supabase shared-room support.
- Added backward migration from the v0.1 localStorage save key.
- Reworked responsive light/dark competition-cockpit UI.

### Model boundary

This project remains an independent training simulator. It does not claim to reproduce proprietary TopBoss formulas.
